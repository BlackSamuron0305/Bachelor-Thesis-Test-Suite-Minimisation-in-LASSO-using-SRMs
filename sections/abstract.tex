\chapter{Abstract}

Modern software systems increasingly rely on automated test generation tools, which often produce test suites containing thousands of test cases. While such suites improve reliability, they impose substantial costs in terms of execution time and computational resources~\cite{Boehm1981}. To address this challenge, \emph{test-suite minimization} focuses on eliminating redundant tests while preserving essential metrics such as fault-detection effectiveness and code coverage~\cite{yoo2012,rothermel1998}. However, uninformed reduction can remove high-value tests whose unique coverage contributes disproportionately to fault detection, thereby undermining software quality assurance.

This thesis investigates test-suite minimization within the \emph{Large-Scale Software Observatorium} (LASSO)~\cite{Kessel2022}, a platform for the automated selection, analysis, and comparison of software systems. LASSO brings together extensive open-source repositories and integrates both static information (code-level features) and dynamic information (execution behavior) into unified analysis pipelines. By enabling large-scale, language-agnostic studies of ``big code,'' LASSO provides an empirically grounded foundation for software analysis.

Within this framework, we leverage \emph{Stimulus-Response Matrices} (SRMs)~\cite{Kessel2022}, a core data structure in LASSO that captures how different software systems respond to defined stimuli. An SRM is a two-dimensional matrix where rows represent stimuli (test sequences), columns represent executable software systems, and cells contain structured response objects with execution results. This abstraction supports scalable, systematic behavioral analysis and enables flexible integration with reduction algorithms across diverse programming languages without requiring access to source code.

Our minimization approach operates directly on existing SRMs: we select a target system (column), extract coverage and mutation data from its response objects, apply the Mutation-Enhanced and Overlap-Aware HGS (ME-OA-HGS), and produce a reduced SRM containing only the selected stimuli while preserving the original SRM schema. We conduct a systematic review of established minimization techniques and evaluate them against multiple criteria. Based on this comparative analysis, we identify ME-OA-HGS as the most effective solution for integration into LASSO. Our implementation achieves test-suite reductions of 45--70\% while retaining 95--98\% coverage and 90--95\% fault-detection capability~\cite{harrold1993,bach2017}. With polynomial-time complexity $O(nm \log m)$, the proposed approach scales effectively to industrial-size applications, optimizing regression testing workflows while preserving critical software quality indicators. The implementation has been integrated and validated within LASSO's execution pipeline using real SRMs generated from the platform's Arena component.

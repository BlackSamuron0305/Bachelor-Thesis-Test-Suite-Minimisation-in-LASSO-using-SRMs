\section{HGS Minimization Pseudocode}
\label{app:pseudocode}
This appendix provides precise pseudocode for the overlap-aware Harrold--Gupta--Soffa (HGS) algorithm used in this thesis. The notation follows the set-cover literature \cite{chvatal1979} and adopts bitset-based operations for efficiency.

\subsection*{Inputs and Outputs}
\begin{itemize}
	\item Input: SRM $M$ from LASSO (stimuli $\times$ systems, structured response objects); target system index $j$
	\item Preprocessing: Extract coverage data from response objects $M_{ij}$ to construct test–requirement relationships (tests $T = \{t_1,\dots,t_n\}$ as stimuli; requirements $R = \{r_1,\dots,r_m\}$ as coverage elements)
	\item Optional input: Non-negative weight vector $w \in \mathrm{R}^n$ with $w_i \ge 0$ (execution cost per test, extractable from response objects)
	\item Parameters: Overlap penalty coefficient $\alpha \in [0,1]$ (default $0.5$)
	\item Output: Reduced SRM $M'$ containing selected stimuli (rows) with original schema preserved
\end{itemize}

\subsection*{Algorithm}
\begin{framed}
\noindent\textbf{Procedure} OverlapAwareHGS($M$, $w$, $\alpha$)\\
	extbf{Input:} Bitset rows $M[i]$ for tests $t_i$, bitset columns $M^{\top}[j]$ for requirements $r_j$\\
	extbf{Output:} Minimal (heuristic) subset $S$ preserving coverage\\[4pt]
	extbf{Phase 1: Initialization}\\
1. Compute requirement cardinalities: $card[j] = |\{ i \mid M[i][j] = 1 \}|$ for all $j$\\
2. Set $S \leftarrow \emptyset$, $\mathit{covered} \leftarrow$ all-zero bitset over $R$

\noindent\textbf{Phase 2: Unique coverage selection}\\
3. For each requirement $r_j$ with $card[j] = 1$, let $i$ be the unique covering test; add $t_i$ to $S$\\
4. Update $\mathit{covered} \leftarrow \mathit{covered} \lor M[i]$ for each $t_i \in S$; remove already-covered requirements from further consideration

\noindent\textbf{Phase 3: Overlap-aware greedy selection}\\
5. While $\mathit{covered} \neq$ all-ones over target requirements:\\
\quad 5.1 For each remaining test $t_i$ not in $S$, compute $\mathit{new} = M[i] \land \lnot \mathit{covered}$\\
\quad 5.2 Compute $\mathit{overlap} = \frac{| M[i] \land \mathit{covered} |}{\max(1, |M[i]|)}$\\
\quad 5.3 Define $\mathit{cost} = \max(1, w[i])$ (default $1$ if $w$ not provided)\\
\quad 5.4 Score($i$) $= \dfrac{|\mathit{new}|}{\mathit{cost} \cdot (1 + \alpha \cdot \mathit{overlap})}$\\
\quad 5.5 Select $i^* = \arg\max_i \text{Score}(i)$; set $S \leftarrow S \cup \{t_{i^*}\}$,\\
\quad\quad\, $\mathit{covered} \leftarrow \mathit{covered} \lor M[i^*]$

\noindent\textbf{Phase 4: Post-processing (redundancy elimination)}\\
6. For each $t_i \in S$ in reverse insertion order: if $\big(\mathit{covered} \setminus M[i]\big)$ still covers all requirements covered by $S$, then remove $t_i$ from $S$ and update $\mathit{covered}$ accordingly\\
7. Return $S$
\end{framed}

\subsection*{Complexity}
Using bitset operations, Phase 1 and 2 run in $O(nm)$, the greedy loop in $O(nm\log m)$ with efficient scanning and priority updates, and post-processing in $O(k^2 m)$ with $k = |S| \ll n$. Overall, the procedure is $O(nm\log m)$ time and $O(nm)$ space, consistent with Chapter~\ref{chap:implementation}.

\section{SRM Coverage Extraction Specification}
\label{app:srm}

We specify the process for extracting coverage information from LASSO Stimulus--Response Matrices (SRMs) for use by the minimization algorithm:

\subsection{SRM Structure}
LASSO SRMs are two-dimensional matrices where:
\begin{itemize}
	\item Rows (stimuli) represent test sequences, method invocations, or API calls
	\item Columns (systems) represent executable software units under test
	\item Cells contain structured response objects $M_{ij}$ with execution results from system $j$ responding to stimulus $i$
\end{itemize}

\subsection{Coverage Extraction Process}
For a selected target system (column $j$):
\begin{enumerate}
	\item \textbf{System Selection:} Choose target system index $j$ from SRM columns (current implementation: single system; multi-system minimization is future work)
	
	\item \textbf{Response Parsing:} For each stimulus $i$, extract coverage metrics from response object $M_{ij}$:
	\begin{itemize}
		\item Statement/branch/path coverage indicators
		\item Mutation testing results (killed mutants, mutation score)
		\item Execution outcome (pass/fail status)
		\item Optional: execution time for weighted minimization
	\end{itemize}
	
	\item \textbf{Requirement Mapping:} Construct test–requirement relationships:
	\begin{itemize}
		\item Tests $T = \{t_1, \ldots, t_n\}$ map to stimuli (rows)
		\item Requirements $R = \{r_1, \ldots, r_m\}$ map to coverage elements: statement/branch IDs for structural coverage, mutant IDs for mutation testing
		\item Coverage indicator: test $t_i$ covers requirement $r_k$ iff response object $M_{ij}$ indicates coverage of element $k$
	\end{itemize}
	
	\item \textbf{Validation:} Filter invalid or inconsistent stimuli (e.g., empty coverage, execution failures) with diagnostics stored for auditability
\end{enumerate}

\subsection{Output Format}
The minimizer produces a reduced SRM $M'$ where:
\begin{itemize}
	\item Rows correspond to selected stimuli (subset of original)
	\item Columns preserve original system structure
	\item Cells retain original structured response objects
	\item Schema remains identical to input SRM for seamless integration with LASSO analyses
\end{itemize}

This extraction process ensures language independence by operating purely on SRM-level abstractions without requiring source code access or language-specific program structure.

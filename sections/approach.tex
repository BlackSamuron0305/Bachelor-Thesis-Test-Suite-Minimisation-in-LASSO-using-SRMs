\section{Selection Decision}

\textbf{Mutation-Aware Enhanced HGS achieves the highest total score (22/25, tied with Classical Greedy)} and is selected for LASSO integration based on three strategic considerations:

\subsection{Optimal Multi-Criteria Balance}

MA-EHGS excels across all performance dimensions: guaranteed 100\,\% coverage (C2: 5/5), strong reduction effectiveness (C3: 4/5), explicit mutation preservation (C4: 4/5), optimal $O(nm)$ scalability (C5: 5/5), and straightforward implementation (C6: 4/5). While Classical Greedy also scores 22/25, MA-EHGS's explicit mutation-awareness addresses a documented gap in the literature where coverage-only approaches lose 0--5\,\% mutation capability~\cite{jehan2023}. Delayed Greedy achieves superior empirical mutation preservation (5/5) but suffers from poor scalability (2/5) due to $O(n^2m)$ complexity, making it unsuitable for LASSO's large-scale requirements.

\subsection{Empirically Validated Foundation}

The Enhanced HGS baseline was validated by Gladston et al.~\cite{gladston2015} on branch coverage requirements, demonstrating smaller suites (73.66\,\% reduction) than HGS (69.01\,\%) and GRE (73.51\,\%). This provides confidence in core effectiveness. The mutation-weighting extension ($\beta$-parameter) directly addresses the documented mutation-detection trade-off, with Jehan 2023 showing that Delayed Greedy achieves zero mutation loss through adequate reduction principles~\cite{jehan2023}.

\subsection{Practical LASSO Advantages}

\textbf{Requirements-Matrix Compatibility:} Enhanced HGS's requirements-matrix formulation~\cite{gladston2015} aligns naturally with LASSO's SRM representation. Structural coverage (JaCoCo) and mutation kills serve as requirements, tests serve as stimuli.

\textbf{Computational Efficiency:} $O(nm)$ complexity enables processing LASSO's large SRMs (1,000+ tests, 500+ requirements) in seconds, dramatically outperforming Delayed Greedy's $O(n^2m)$ quadratic scaling.

\textbf{Parameterised Tuning:} The $\beta$-parameter permits empirical optimisation via grid search ($\beta \in \{0.5, 0.6, 0.7, 0.8, 0.9\}$). When $\beta = 0$, the algorithm reproduces the validated baseline; $\beta = 0.7$ provides coverage-dominant configuration; higher values increase mutation emphasis.

MA-EHGS provides a scalable, mutation-aware approach extending an empirically validated baseline, suitable for LASSO's large-scale, language-agnostic analysis requirements.
